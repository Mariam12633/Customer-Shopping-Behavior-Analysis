# Customer Shopping Behavior Analysis

## Project Overview

An end-to-end data analysis project using a dataset of 3,900 customer shopping records to explore purchasing patterns and customer behavior.

## Tools Used

- **Python (pandas):** Data cleaning and preparation.
- **PostgreSQL / SQL:** Data analysis and business queries.
- **Power BI:** Interactive dashboard and data visualization.

## Project Workflow

1. Explored and cleaned the dataset using Python.
2. Prepared and transformed the data for analysis.
3. Loaded the data into PostgreSQL.
4. Performed 10 SQL queries to analyze customer behavior.
5. Created an interactive dashboard in Power BI.

## Business Insights

The analysis examines customer spending, popular products, subscriptions, discounts, and purchasing patterns.

## Recommendations

- Encourage customer subscriptions.
- Improve customer loyalty.
- Optimize discount strategies.
- Promote popular and highly rated products.
